What I built

Hardware acceleration that has a complete data path.

For a real-time signal-processing project, the Processing System generated waveforms, data moved through DMA to the Programmable Logic for FFT processing, returned to the PS for image formation, and then moved through VDMA for HDMI display. A second project implemented Sobel edge detection in PL for camera imagery.

Why it mattered

Data movement is part of the design.

FPGA performance is not only determined by the RTL algorithm. The partition between PS and PL, interface design, DMA/VDMA buffering, and display pipeline all decide whether an accelerator becomes a real-time system.
